# XML Tag Expander

Chrome extension: type `:name` + Tab to get `<name></name>` with the cursor inside. Tab again jumps past the closing tag.

## Customize shortcuts

Click the extension icon to add, edit or remove shortcuts (e.g. `:ins` → `<instruction></instruction>`). Changes apply instantly.

## Install

1. Download and unzip this repo.
2. Open `chrome://extensions`, enable **Developer mode**.
3. Click **Load unpacked** and pick the folder with `manifest.json`.
